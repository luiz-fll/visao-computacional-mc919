# visao-computacional-mc919

## Configuração do ambiente

O projeto utiliza um ambiente virtual Python (`venv`) para manter as dependências isoladas.

```bash
source .venv/bin/activate
```

Para verificar se o Python correto está sendo utilizado:

```bash
which python
```

### Instalar as dependências

Com a `venv` ativada:

```bash
pip install -r requirements.txt
```
